Binder documentation summary — quick index

This file summarizes the most important docs included in the `binder/` package so you can find what you need quickly.

- INSTALL.md — Quick start and XAMPP instructions (included in binder root)
- README.md — Project overview and high-level notes (copied into `binder/docs/`)
- DEPLOYMENT.md — Full deployment guide and steps
- DEPLOYMENT_CHECKLIST.md — Short checklist for production deployment
- PRODUCTION_READY.md / PRODUCTION_SECURITY.md — Hardening and production notes
- SECURITY_AUDIT.md / SECURITY_CAPTCHA.md — Security findings and CAPTCHA notes
- PENETRATION_REPORT.md — Recent pentest summary
- TODO_DEVOPS.md / TODO_SECURITY.md — outstanding tasks and action items

For convenience there is also `CONSOLIDATED_DOCS.md` which bundles the core docs into
one file suitable for offline reading. Use `binder/scripts/install.sh` to import the
database schema and optionally seed minimal data.
